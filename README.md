# Reddy AI Toolbox

用 AI 辅助开发和改造的个人小工具集合。这里主要放可下载、可查看源码、可继续二次改造的小工具。

## 工具列表

| 工具 | 类型 | 简介 | 入口 |
| --- | --- | --- | --- |
| DeepSeek DeskBand | Win 任务栏工具 | 在任务栏显示 DeepSeek API 余额 | [安装包](https://github.com/leidichen/reddy-ai-toolbox/releases/latest/download/DeepSeekDeskBand.msi) / [源码说明](tools/deepseek-deskband/README.md) |

## 说明

每个工具尽量独立维护，详细安装、卸载、截图、已知限制都放在对应工具目录的 README 里。

改装第三方项目时，会在工具说明或 [许可与来源说明](docs/license-notes.md) 中记录原项目来源和许可证。
