# Obsidian Plugin Mods

## 简介

这里整理基于个人知识库工作流改造过的 Obsidian 插件或插件片段。

这些改装通常不是面向所有人的通用插件，而是为了更贴合我的 Obsidian 使用习惯、文件结构、模板方式和笔记整理流程。

- 对原插件行为的轻量调整。
