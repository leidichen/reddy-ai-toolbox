# DeepSeek Balance Tray

## 简介

一个用于 Windows 的托盘小工具，用来快速查看 DeepSeek API 余额或相关账户状态。

## 适用场景

- 经常使用 DeepSeek API，希望随时了解余额。
- 不想反复打开网页后台查看账户状态。
- 希望在桌面环境里有一个轻量提醒入口。

## 当前状态

计划中。

## 功能规划

- 托盘区域显示余额或简短状态。
- 定时刷新账户余额。
- 余额低于阈值时提醒。
- 支持本地配置 API Key。
- 支持开机自启动。
