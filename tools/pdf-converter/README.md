# PDF Converter

## 简介

一个面向本地使用的 PDF 转换与处理工具，用于整理日常文档转换需求。

## 适用场景

- PDF 转图片。
- PDF 提取文本。
- PDF 页面拆分或合并。
- 本地批量处理文档。
