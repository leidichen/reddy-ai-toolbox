# 许可与来源说明

本仓库默认使用 MIT License。

## 处理原则

- 如果是完全原创的小工具，可以使用本仓库默认许可证。
- 如果基于第三方开源项目修改，必须保留原项目许可证和版权声明。
- 如果原项目许可证不允许再发布，不应直接把源码放入本仓库。
- 如果只记录个人配置或改装思路，也要明确说明来源。
